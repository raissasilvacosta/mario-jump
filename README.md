### Um mini game inspirado no universo do Mario desenvolvido com HTML, CSS e JavaScript. O objetivo é simples: desviar dos canos e sobreviver o máximo possível 🚀

## ✨ Preview

![mario-jump](/img/Captura%20de%20Tela%20(11).png)

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript

## 🎯 Funcionalidades
- Sistema de pulo
- Detecção de colisão
- Game Over
- Animações com CSS
- Movimentação automática dos obstáculos
- Estilo retrô em pixel art


## 📂 Estrutura do projeto
```txt
📂 Primeiro Jogo
 | 📂 css

 | 📂 js
 |-- script.js
 |-- index.html
 |-- mario.gif
 |-- pipe.png
 |-- clouds.png
 |-- README.md
```

## 🕹️ Como jogar
1. Abra o projeto no VS Code

3. Execute o 
```index.html```

4. Pressione qualquer tecla para fazer o Mario pular
